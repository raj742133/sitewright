Tear-off confirm

A confirm button with a perforated stub: drag it off or press Space on it to confirm, then Reset.

Full screen
480 px

What it is for

sign-in confirmation, publish or delete confirmation, checkout, landing call to action

Use it

1 · site.json
"effects": { "components": ["tear-button"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --components tear-button
2 · import it
import { TearButton } from '@/components/fx/ui';

Files

  • components/fx/ui/TearButton.tsx
  • components/fx/ui/_n1.ts
  • ui-tear-button.css styles

Source

Idea from Kokonut UI; the code is written for this kit.

Credits and licences: third-party notices.

Accessibility

  • Keyboard. Components in the kit are written to be reached and used with the keyboard. Try it: press Tab inside the preview.
  • Reduced motion. With prefers-reduced-motion on, animation settles to its finished state at once.
  • Touch. Pointer-follow effects are skipped on touch screens; controls stay finger-sized.
