Ring rope upload

Circular upload ring that unrolls into a straight progress bar, then tosses a file chip to the right end and shows a done check; falls back to a plain progress bar for reduced motion.

Full screen
480 px

What it is for

file upload field in a dashboard, application form or publishing flow

Use it

1 · site.json
"effects": { "components": ["ring-rope-upload"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --components ring-rope-upload
2 · import it
import { RingRopeUpload } from '@/components/fx/ui';

Files

  • components/fx/ui/RingRopeUpload.tsx

Accessibility

  • Keyboard. Components in the kit are written to be reached and used with the keyboard. Try it: press Tab inside the preview.
  • Reduced motion. With prefers-reduced-motion on, animation settles to its finished state at once.
  • Touch. Pointer-follow effects are skipped on touch screens; controls stay finger-sized.
