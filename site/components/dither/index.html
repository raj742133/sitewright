Dither

An animated wave field quantised with an 8x8 ordered Bayer dither into square pixels in brand tones; the pointer raises a bump.

Full screen
480 px

What it is for

Behind a retro or technical hero (first child of a position:relative section; fills its parent).

Use it

1 · site.json
"effects": { "components": ["dither"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --components dither
2 · import it
import { Dither } from '@/components/fx/ui';

Accessibility

  • Keyboard. Components in the kit are written to be reached and used with the keyboard. Try it: press Tab inside the preview.
  • Reduced motion. With prefers-reduced-motion on, animation settles to its finished state at once.
  • Touch. Pointer-follow effects are skipped on touch screens; controls stay finger-sized.
