Radar chart

Spider chart with up to three series polygons, grid rings and focusable vertices with tooltips.

Full screen
480 px

What it is for

comparison pages, skill or product profiles, dashboard scorecards

Use it

1 · site.json
"effects": { "components": ["radar-chart"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --components radar-chart
2 · import it
import { RadarChart } from '@/components/fx/ui';

Files

  • components/fx/ui/RadarChart.tsx
  • components/fx/ui/_b2.tsx
  • ui-chart2.css styles

Source

Idea from Bklit; the code is written for this kit.

Credits and licences: third-party notices.

Accessibility

  • Keyboard. Components in the kit are written to be reached and used with the keyboard. Try it: press Tab inside the preview.
  • Reduced motion. With prefers-reduced-motion on, animation settles to its finished state at once.
  • Touch. Pointer-follow effects are skipped on touch screens; controls stay finger-sized.
