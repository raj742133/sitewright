Draggable spring

Drag, flick and throw a card with momentum, edge bounce and optional snap grid; arrow keys nudge.

Full screen
480 px

What it is for

playful dashboard widgets, landing page toys, kanban-style pickers

Use it

1 · site.json
"effects": { "components": ["draggable-spring"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --components draggable-spring
2 · import it
import { DraggableSpring } from '@/components/fx/ui';

Files

  • components/fx/ui/DraggableSpring.tsx

Source

Idea from Anime.js; the code is written for this kit.

Accessibility

  • Keyboard. Components in the kit are written to be reached and used with the keyboard. Try it: press Tab inside the preview.
  • Reduced motion. With prefers-reduced-motion on, animation settles to its finished state at once.
  • Touch. Pointer-follow effects are skipped on touch screens; controls stay finger-sized.
