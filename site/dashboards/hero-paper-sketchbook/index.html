Paper sketchbook hero

An illustrator's portfolio built as a paper world: drawn SVG plates on warm paper, a sketchbook whose pages turn by drag or arrow keys with a 3D leaf and travelling shade, a magnifier loupe over the artwork, a filterable commissions index, a rates dialog and a validated contact form.

Full screen

What it is for

illustrator, artist or designer portfolio; any personal site that should feel handmade

Add it to a site

1 · site.json
"effects": { "templates": ["hero-paper-sketchbook"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --templates hero-paper-sketchbook
2 · import it
import HeroPaperSketchbook from '@/components/fx/tpl/HeroPaperSketchbook';

About it

Original to Sitewright. MIT licensed. Demo data is fictional and deterministic. Every control on the page works, so try it before you take it.

It answers its own width rather than the screen's, so the tablet and phone buttons show the real responsive behaviour. Templates are not components: they are chosen with templates, not components.
