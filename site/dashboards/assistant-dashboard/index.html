AI assistant

A conversation next to the answer: ask in plain words and the panel on the right builds a chart or table with its sources and a short summary.

Full screen

What it is for

Analytics copilots, internal data tools, reporting assistants.

Add it to a site

1 · site.json
"effects": { "templates": ["assistant-dashboard"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --templates assistant-dashboard
2 · import it
import AssistantDashboard from '@/components/fx/tpl/AssistantDashboard';

About it

Original to Sitewright. MIT licensed. Demo data is fictional and deterministic. Every control on the page works, so try it before you take it.

It answers its own width rather than the screen's, so the tablet and phone buttons show the real responsive behaviour. Templates are not components: they are chosen with templates, not components.
