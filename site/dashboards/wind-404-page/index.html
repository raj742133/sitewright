Wind 404 page

An illustrated landscape 404 where the headline letters bend away from the pointer on springs, with gentle automatic gusts on touch, a home button and search suggestions.

Full screen

What it is for

404 / not found page

Add it to a site

1 · site.json
"effects": { "templates": ["wind-404-page"] }
or on the command line
node ~/.claude/skills/sitewright/scripts/scaffold.mjs --config site.json --out ./my-site --templates wind-404-page
2 · import it
import Wind404Page from '@/components/fx/tpl/Wind404Page';

Files

  • components/fx/tpl/Wind404Page.tsx
  • components/fx/tpl/_shared.tsx
  • ui-wind-404-page.css styles

About it

Original to Sitewright. MIT licensed. Demo data is fictional and deterministic. Every control on the page works, so try it before you take it.

It answers its own width rather than the screen's, so the tablet and phone buttons show the real responsive behaviour. Templates are not components: they are chosen with templates, not components.
